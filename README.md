# Heart-Disease-project
# Predictive Modeling Using Machine Learning

## Project Overview

This project predicts whether a person has heart disease using Machine Learning techniques.

## Objective

Develop a predictive model using supervised learning and evaluate its performance.

## Dataset

Heart Disease Dataset

## Tools Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm

- Random Forest Classifier

## Steps

1. Load the dataset
2. Preprocess the data
3. Split into training and testing sets
4. Train Random Forest model
5. Make predictions
6. Evaluate using Accuracy, Confusion Matrix and ROC Curve
7. Visualize Feature Importance

## Evaluation Metrics

- Accuracy
- Classification Report
- Confusion Matrix
- ROC Curve
- AUC Score

## Expected Outcome

A trained machine learning model capable of predicting heart disease with high accuracy while demonstrating supervised learning concepts.

## Technologies

- Python
- Pandas
- Matplotlib
- Scikit-learn
